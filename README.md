# 🤖 AI & Automation Knowledge Assessment

A web-based **AI & Automation assessment platform** designed to evaluate knowledge covered in class, including RAG, LLMs, NLP, AI vs traditional systems, OpenAI Codex, and n8n.

## ✨ Features

* 📝 30 Questions
* ⏱️ 20-Minute Time Limit
* 🎯 MCQ + Written Questions
* 🔄 Free Question Navigation
* 🗺️ Question Map
* ⏰ Automatic Submission
* 📊 Instant Results
* 👤 Optional Student Name
* 📱 Responsive Interface

## 📚 Topics Covered

* RAG (Retrieval-Augmented Generation)
* LLM (Large Language Models)
* NLP (Natural Language Processing)
* AI vs Traditional Systems
* OpenAI Codex
* n8n Workflow Automation

## 🛠️ Technologies

* JavaScript
* Bootstrap 5.3.3

## 🚀 How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in a browser.
4. Enter your name (optional).
5. Click **Begin Assessment**.

No backend or database is required.
